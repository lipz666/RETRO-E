# control_metrics.INVALID.json 不是结果

该文件由 2026-09-14 被配额冷却中断的对照复核写出。其中的 `net = -0.750`
**不构成任何证据**，已重命名以防被误引。

中断原因：`HTTP 429 model_cooldown`，judge 模型 `gemini-3.7-flash-high` 的凭据进入冷却
（五小时配额窗口，此前实测约 153 分钟）。注意这与 phase 2 那次的 `503 auth_unavailable`
是**不同故障**：那次是上游鉴权整体挂掉，这次是配额用尽。

为何不可用：

| 项 | 计划 | 实际 |
|---|---:|---|
| 判定配对 | 300 | **5**，且 5/5 由有效性规则判决 |
| E_star 生成 | 300 | 198（被切断） |
| E0 生成 | 300 | 300 ✅ |

「5/5 由有效性规则判决」意味着这 5 对压根没有调用 judge —— 它们是一方路线无效、按预先声明
的规则自动定胜负的。**可用的 judge 裁决为零**，所以 −0.750 反映的是 5 个随机无效样本，
与 E\* 或 E0 的质量无关。

已落盘可复用：498 次生成（E0 300 + E_star 198），约 10.5M token，未受影响。
恢复后重跑同一命令即可补齐：E_star 缺 102 次生成，判定缺约 295 对。
